## 🚀 Быстрый запуск

### Вариант 1: Через BAT-файл (рекомендуется)
```
1️⃣ Щелкните правой кнопкой на Start_PS.bat
2️⃣ Выберите "Запустить от имени администратора"
3️⃣ Следуйте инструкциям на экране
```

### Вариант 2: Через PowerShell
```powershell
# Запустите PowerShell от имени администратора, затем:
Set-Location "путь\к\папке\NewPC"
Set-ExecutionPolicy Bypass -Scope Process -Force
.\NewPC.ps1
```

### 📋 Описание файлов

| Файл | Описание | Статус |
|:-----|:---------|:------:|
| **`NewPC.ps1`** | Основной скрипт с возможностью автоматической загрузки отсутствующих компонентов (7-Zip, AnyDesk). Выполняет полную настройку системы: удаление приложений, конфигурацию параметров, установку ПО и управление пользователями. | <div align="center">✅<br>**Обязателен**</div> |
| **`NewPC_offline.ps1`** | Оффлайн-версия без функции загрузки. Требует наличия всех установщиков локально. Идеальна для изолированных сред без доступа к интернету. | <div align="center">🔄<br>Альтернатива</div> |
| **`Get-PCInventory.ps1`** | Скрипт инвентаризации системы. Собирает детальную информацию о железе и ПО, генерирует отчёты в форматах CSV и HTML. Может запускаться автономно или вызываться основным скриптом. | <div align="center">⚙️<br>Опциональный</div> |
| **`Start_PS.bat`** | Вспомогательный запускатель PowerShell с проверкой прав администратора и настройкой политики выполнения. Обеспечивает корректный запуск сеансов PowerShell. | <div align="center">🔧<br>Вспомогательный</div> |
| **`config.json`** | Критичный файл конфигурации со списками приложений для удаления (Win10/11) и настройками реестра для блокировки рекламного контента Microsoft. | <div align="center">✅<br>**Обязателен**</div> |
| **`UninstallOneDrive.ps1`** | Специализированный скрипт для полного удаления OneDrive, включая все служебные задачи и записи реестра. Вызывается основным скриптом по выбору пользователя. | <div align="center">⚙️<br>Опциональный</div> |
| **`7z_Assoc_OnlyWin10.bat`** | Пакетный скрипт для регистрации 7-Zip как обработчика по умолчанию для всех поддерживаемых форматов архивов. Только для Windows 10 (в Win11 ассоциации работают иначе). | <div align="center">⚙️<br>Опциональный</div> |
| **`7zXXX-x64.msi`** | Официальный MSI-установщик 7-Zip (64-битная версия). Скрипт автоматически обнаруживает файлы по маске `7z*.msi` для тихой установки. | <div align="center">📦<br>Опциональный¹</div> |
| **`AnyDesk.exe`** | Официальный установщик AnyDesk для тихой системной установки с автоматической конфигурацией параметров безопасности и генерацией пароля. | <div align="center">📦<br>Опциональный¹</div> |
| **`ApplyUI-tweaks.ps1`** | Применяет UI-настройки для всех профилей пользователей (активные, оффлайн и дефолтный). Настраивает проводник, панель задач, поиск и другие элементы интерфейса. | <div align="center">⚙️<br>Опциональный</div> |

> ¹ **Примечание:** Установщики строго обязательны только для **оффлайн-версии** (`NewPC_offline.ps1`). **Полная версия** (`NewPC.ps1`) может загружать их автоматически при отсутствии локальных файлов.

## 💽 Версии скриптов

### 🌐 Полная версия (`NewPC.ps1`)

**Особенности:**
- 📡 Автоматическая загрузка отсутствующих компонентов
- 🔄 Проверка актуальности версий 7-Zip и AnyDesk
- 🌍 Загрузка с официальных источников
- ✅ Проверка целостности загруженных файлов

**Рекомендуется для:**
- Систем с подключением к интернету
- Массового развёртывания с актуальными версиями ПО
- Ситуаций, где нужны последние обновления компонентов

### 💾 Оффлайн-версия (`NewPC_offline.ps1`)

**Особенности:**
- 🔌 Работа без подключения к интернету
- 📦 Использование локальных установщиков
- ⚡ Более быстрое выполнение
- 🎯 Предсказуемость версий компонентов

**Рекомендуется для:**
- Систем без доступа к интернету
- Ситуаций, требующих строго определённых версий ПО
